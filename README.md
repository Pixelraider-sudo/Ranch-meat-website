# Ranch Platform

A modern, enterprise-grade farm-to-table marketplace built to connect customers, farmers, restaurants, and wholesalers through a premium digital commerce experience.

> **Status:**  Under Active Regeneration

---

## Overview

Ranch Platform is being rebuilt from the ground up as a production-ready web application focused on modern frontend engineering, scalability, accessibility, and future API integration.

The project serves as a learning and portfolio platform for building commercial-grade software using modern web technologies and best engineering practices.

---

## Vision

The goal is to create a premium digital agriculture ecosystem that enables:

- Customers to discover and purchase quality meat products.
- Farmers to showcase and manage their livestock and products.
- Restaurants and businesses to place bulk orders.
- Administrators to manage products, users, orders, and analytics.

The application emphasizes:

- Transparency
- Trust
- Quality
- Performance
- Scalability
- User Experience

## Getting Started

Clone the repository

```bash
git clone https://github.com/Pixelraider-sudo/Ranch-meat-website.git
```

Navigate into the project

```bash
cd Ranch-meat-website
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Create a production build

```bash
npm run build
```
